# Flappy Bird
This Is Flappy Bird. A Classic Game That were made on watches now on webs.

# Story Behind Making This
On One day I was Just sitting And playing Flappy Bird On My Watch, Then After Some time I Realised That I Can Make this as a Website on Stardance Hackclub. So from This The Idea Of flappy bird Began!

# Features
1] This is Made By HTML, CSS & JavaScript
2] There is One Developer Mode That we will discuss as topic next
3] Congratulations on breaking the high score
4] Developer Mode Requires a password
5] Fully Functional
6] Improved hitboxes than the ship-1
